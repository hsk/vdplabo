# 参考: 第三者製サンプル

`lib.asm` / `sp1pri.asm` は、このディレクトリの `sc5_sp*` シリーズとは別に、
t.hara (HRA!) 氏による V9968 用スプライト優先順位・衝突テストプログラムを
参考として置いているものです。

- 出典: https://github.com/hra1129/V9968_Cartridge/blob/main/fpga/V9968_Cartridge_TangNano20K/src/v9968/test_pattern/sprite/sp1pri.asm

`sp.png` はこのプログラムの実行結果のスクリーンショットです。

このディレクトリの内容は `sprite2/Makefile` のビルド対象には含まれません。
