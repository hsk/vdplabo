# SCREEN 1 でスプライトを1つ表示する

このサンプル [sc1_sp01.asm](../sprite1/sc1_sp01.asm) は MSX の SCREEN 1 モードでスプライトを1つ表示する最小構成のカセットROMです。

## ビルド方法

このサンプル集は MSX 用アセンブラソースを収録しています。

アセンブラには Glass Assembler を使用しています。

必要なファイル:

- glass-0.6.jar

付属の Makefile を利用して ROM イメージを生成できます。

```make
TARGETs = sc1_sp01 sc1_sp02 sc1_sp03 sc1_sp04 \
          sc1_sp05 sc1_sp06 sc1_sp07 sc1_sp08

all: $(TARGETs)

sc%:
	java -jar glass-0.6.jar $@.asm rom/$@.rom
#	../../../../../msxemu/msx2_sdl/app rom/$@.rom
#	openmsx -carta rom/$@.rom

clean:
	rm -rf rom/*.rom
```

## ビルド

例えば `sc1_sp01` をビルドする場合は次のように実行します。

```bash
make sc1_sp01
```

成功すると次の ROM ファイルが生成されます。

```text
rom/sc1_sp01.rom
```

## エミュレータで実行

Makefile には実行用コマンドも用意されています。

```make
#	../../../../../msxemu/msx2_sdl/app rom/$@.rom
#	openmsx -carta rom/$@.rom
```

コメントアウトを外すことで、

- 自作エミュレータ (`msx2_sdl`)
- openMSX

でビルド後に自動実行できます。

## sc1_sp01.asm について

ソースコード: [sc1_sp01.asm](../sprite1/sc1_sp01.asm)

表示されるスプライトは次のような8×8ドットの円形パターンです。

```
   ####
  ######
 ########
 ########
 ########
 ########
  ######
   ####
```

表示位置は X=100, Y=100 です。

---

## 使用している BIOS

MSX には BIOS が用意されており、画面モード変更や VRAM 転送などを簡単に行えます。

このサンプルでは以下の BIOS を利用しています。

| ラベル   | アドレス | 内容                |
|----------|----------|---------------------|
| CHGMOD   | 005Fh    | 画面モード変更      |
| WRTVDP   | 0047h    | VDPレジスタ書き込み |
| LDIRVM   | 005Ch    | RAM→VRAM転送        |

```asm
WRTVDP equ 00047h
CHGMOD equ 0005Fh
LDIRVM equ 0005Ch
```

---

## ROMヘッダ

MSX のカセットROMには先頭にヘッダが必要です。

```asm
org 04000h
db "AB"
dw init
dw 0,0,0,0,0
```

AB は ROM であることを示す識別子です。

その後に実行開始アドレスを記述します。

このサンプルでは init が起動時に呼ばれます。

---

## SCREEN 1 に切り替える

最初に SCREEN 1 に切り替えます。

```asm
ld a,1
call CHGMOD
```

SCREEN 1 はテキストとスプライトを組み合わせて利用できる画面モードです。

---

## スプライトを2倍サイズにする

VDPレジスタ1の設定を変更してスプライト拡大を有効にします。

```asm
ld a,(RG1SAV)
or 00000001b
ld b,a
ld c,1
call WRTVDP
```

設定後は8×8スプライトが16×16相当で表示されます。

---

## スプライトパターンをVRAMへ転送

スプライトの形状データをVRAMへ転送します。

```asm
ld de,SPRPAT
ld hl,sprite_pattern_data
ld bc,8
call LDIRVM
```

転送されるデータは次の8バイトです。

```asm
db 000111100b
db 001111110b
db 011111111b
db 011111111b
db 011111111b
db 011111111b
db 001111110b
db 000111100b
```

ビットが1の部分が表示されます。

図にすると以下のようになります。

```
..####..
.######.
########
########
########
########
.######.
..####..
```

---

## スプライト属性テーブル

続いてスプライト属性を設定します。

```asm
sprite_attr_data:
    db 100,100,0,15
```

各バイトの意味は次の通りです。

| 値  | 内容         |
|-----|--------------|
| 100 | Y座標        |
| 100 | X座標        |
| 0   | パターン番号 |
| 15  | 色番号       |

色15は白色です。

---

## スプライト属性をVRAMへ転送

属性テーブルをVRAMへ書き込みます。

```asm
ld de,SPRATR
ld hl,sprite_attr_data
ld bc,4
call LDIRVM
```

これによりスプライト0番が画面上に表示されます。

---

## メインループ

初期化後は無限ループに入ります。

```asm
main:
    jr main
```

今回は表示確認だけが目的なので、特別な処理は行いません。

## 実行結果

画面中央付近に白い円形スプライトが表示されます。

```text
SCREEN 1
        ○
```

## このサンプルで学べること

このサンプルでは MSX スプライト表示に必要な最小構成を確認できます。

1. SCREEN 1 に切り替える
2. スプライトパターンをVRAMへ配置する
3. スプライト属性テーブルを設定する
4. VDPが自動的に描画する

以降のサンプルでは、

- 複数スプライト
- 重なり判定
- 1ラインあたりの表示制限
- SCREEN 5 のスプライト
- ORカラー合成

などを調査していきます。
