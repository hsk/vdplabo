# SCREEN 5 のスプライトカラーテーブルを試す

このサンプルは `sc5_sp01` の発展版です。

ソースコード: [sc5_sp02.asm](../sprite2/sc5_sp02.asm)

前回のサンプルでは SCREEN 5 のスプライトオーバー情報を確認しました。

このサンプルでは SCREEN 5 特有の **スプライトカラーテーブル** を利用し、1つのスプライトの中で複数の色を使用する方法を確認します。

---

## このサンプルで学べること

- SCREEN 5 のスプライトカラーテーブル
- ライン単位の色設定
- 1スプライト内で複数色を使う方法
- `SPRATR - 0200h` の意味
- スプライトオーバー情報の確認

---

## SCREEN 5 の初期化

まず SCREEN 5 へ切り替えます。

```asm
ld a, 5
call CHGMOD
```

続いてスプライト拡大機能を有効にします。

```asm
ld a, (RG1SAV)
or 00000001b
call WRTVDP
```

これによりスプライトは拡大表示されます。

---

## スプライトパターンの準備

パターンジェネレータには単純な塗りつぶしパターンを登録しています。

```asm
ld hl, SPRPAT
ld bc, 8
ld a, 255
call BIGFIL
```

各ラインを `11111111b` で埋めるため、四角形のスプライトになります。

---

## SCREEN 5 のカラーテーブル

SCREEN 1 では色番号はスプライト属性テーブルの一部でした。

```text
Y座標 X座標 パターン 色
```

しかし SCREEN 5 では色情報が独立したカラーテーブルとして管理されています。

```text
属性テーブル
Y座標 X座標 パターン

カラーテーブル
ラインごとの色
```

そのため 1 つのスプライトの中で複数色を使用できます。

---

## なぜ `SPRATR - 0200h` を使うのか

MSX2 のスプライトカラーテーブルは、スプライト属性テーブルより 0200h バイト手前に配置されています。

そのため

```asm
ld hl, SPRATR - 0200h
```

とすることで、カラーテーブルへアクセスできます。

このサンプルでは `BIGFIL` を利用してカラーテーブルを初期化しています。

---

## 1つのスプライトに複数色を設定する

このサンプルの中心部分です。

```asm
; 二色
ld bc, 2

; 四色
ld bc, 4

; 二色
ld bc, 2
```

スプライトのカラーテーブルへ

```text
2ライン  色N
4ライン  色N+1
2ライン  色N
```

という並びで色を書き込んでいます。

図にすると次のようになります。

```text
■■■■■■■■  色N
■■■■■■■■  色N

■■■■■■■■  色N+1
■■■■■■■■  色N+1
■■■■■■■■  色N+1
■■■■■■■■  色N+1

■■■■■■■■  色N
■■■■■■■■  色N
```

そのため 1 つのスプライトの中に横縞模様が表示されます。

---

## スプライトごとに色を変える

色番号はレジスタ D で管理しています。

```asm
ld d, 2
```

各スプライトの初期化後に

```asm
inc d
```

を実行しているため、スプライトごとに色が変化します。

```text
スプライト0  色2 / 色3
スプライト1  色3 / 色4
スプライト2  色4 / 色5
...
```

その結果、画面上には異なる色の縞模様スプライトが並びます。

---

## スプライトオーバー確認

後半の処理は `sc5_sp01` とほぼ同じです。

```asm
ld de, STATFL
```

で BIOS が保持するステータス情報を取得しています。

下位 5 ビットは表示できなかったスプライト番号です。

```asm
and 011111b
```

またビット 6 はスプライトオーバーフラグです。

```asm
and 01000000b
```

オーバー発生時は診断用スプライトを赤色で表示しています。

---

## 実行結果

画面上には色の異なるスプライトが並びます。

```text
■

□■□■■□■■□■□

```

それぞれのスプライトは中央部分だけ色が異なる縞模様になります。

さらにスプライトオーバーが発生すると、診断用スプライトの色が変化します。

---

## SCREEN 1 との大きな違い

SCREEN 1 ではスプライトごとに 1 色しか使用できません。

一方 SCREEN 5 ではカラーテーブルを利用することで、ラインごとに色を変更できます。

```text
SCREEN 1
  スプライト全体が同じ色

SCREEN 5
  ラインごとに色を設定可能
```

このサンプルは、その違いを確認するための実験プログラムになっています。
