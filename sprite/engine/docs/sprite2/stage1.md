# sprite2/stage1 について

画面サイズは256x192、スプライトモード2の簡易的リファレンス実装です。
パレットは512色中16色で、スプライトは32個あり色はスプライトの行単位で1色指定できます。
CCビットを立てると描画されていたスプライトの色とORを取った色を描画します。
描画されていない箇所にはそのまま描画します。

このステージでは１画面ごと一気に描画します。

当たり判定や、ラインごとの表示制限はありません。
また指定Y座標のスプライトがあるとそれ以降のスプライトが描画されないということもありません。

## 実装した機能

- [x] 8x8 sprite
- [x] 16x16
- [x] magnify
- [x] sprite color table(行ごとの色指定)
- [x] CCビットによる色の重ね合わせ(OR)

color 0 transparent・当たり判定・9th sprite・scanline化はこの段階では意図的に対象外(Phase 2以降で扱う)。

## sprite1/stage1との違い

- パレット: sprite1は固定16色。sprite2は512色中16色を選べる可変パレット。
- 色指定の粒度: sprite1はスプライト単位で1色。sprite2はスプライトの行
  (パターンの1ライン)単位で1色指定できる(sprite color table)。
- 重ね合わせ: sprite2はCCビットを立てると既に描画されている色とORを取って
  重ね合わせられる。sprite1にはこの機能自体がない。
- それ以外(画面サイズ256x192、32個、1画面ごと一気に描画、当たり判定/
  ラインごとの表示制限なし)はsprite1/stage1と同じ。
