# sprite1/stage2 について

スプライトモード1の簡易的リファレンス実装です。
パレットは固定で、スプライトは32個あり色はスプライト単位で1色指定できます。
行ごとに表示できるスプライト数は4つです。

このステージでは1ラインごとに描画します。

当たり判定はありません。
また指定Y座標のスプライトがあるとそれ以降のスプライトが描画されないということもありません。

このステージではライン番号からスプライトが描画されるかどうかを判定します。
描画できる場合は、ライン番号をスプライトのy座標から引いたスプライトの行を描画します。
行ごとに表示できるようになったので1行ごとのスプライト数による制限も行います。

## 実装した機能

- [x] scanline sprite描画
- [x] 1ライン4枚制限
- [x] 5th sprite
- [x] sprite priority
- [x] collision
- [x] Y判定
- [x] color 0 transparent
- [x] Y=208終端
- [x] Early Clock(EC)

## sprite1/stage2-1: ライン描画導入

- renderLine(y)

- 1ライン単位描画
- background line描画
- sprite line描画
- スプライトリミット

描画構造をscanline化する。
リミットをつけられたけど、優先順位が高いものが描画されない。

## sprite1/stage2-2: 描画済みバッファ導入

- draw_buffer[256]を導入
- 優先順位の高いものから描画しdraw_bufferにも結果を残す

priority管理をして、優先順位が高いものから4つ描画できるようになった。

## sprite1/stage2: collisionフラグ、その他諸機能

- 衝突検出
  - 描画されていたら衝突フラグを立てる
- 透明スプライト制限 色が0なら抜ける
- 208制限 y座標が208のスプライト以降は表示しない
- 32ドットずらし機能 フラグが立っているとx座標を左に32ずらす機能
    画面左から滑らかに登場できるようにする
