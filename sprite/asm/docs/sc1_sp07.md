# SCREEN 1 でイージング付きタイトルアニメーションを作る

このサンプルは `sc1_sp06` の発展版です。

ソースコード: [sc1_sp07.asm](../sprite1/sc1_sp07.asm)

前回のサンプルでは、文字スプライトを一定速度で落下させていました。

このサンプルでは **イージング (Easing)** を導入し、目的地に近づくほど減速する自然なアニメーションを実現しています。

---

## 前回との違い

`sc1_sp06` では毎フレーム一定量だけ移動していました。

```asm
add a, 4
```

つまり移動速度は常に一定です。

```text
位置
│
│      ●
│    ●
│  ●
│●
└──────── 時間
```

一方、このサンプルでは残り距離に応じて移動量を変化させています。

```text
位置
│
│          ●
│         ●
│       ●
│    ●
│●
└──────────── 時間
```

開始直後は大きく移動し、目的地に近づくほどゆっくりになります。

---

## 固定小数点座標

前回は Y 座標を 1 バイトの整数として扱っていました。

このサンプルでは滑らかな移動を行うため、固定小数点座標を使用しています。

スプライト情報は次の 5 バイト構造です。

| オフセット | 内容        |
|------------|-------------|
| +0         | Y座標小数部 |
| +1         | Y座標整数部 |
| +2         | X座標       |
| +3         | パターン    |
| +4         | カラー      |

Y 座標は整数部と小数部を合わせた Q8.8 形式として扱われます。

---

## イージングの仕組み

目標位置は Y=88 です。

```asm
ld bc, 05800h
```

現在位置との差を計算します。

```asm
sbc hl, de
```

ここで求められる値は

```text
残り距離 = 目標位置 - 現在位置
```

です。

---

## 残り距離の 1/8 だけ移動する

このサンプルの核心部分です。

```asm
sra h
rr l
sra h
rr l
sra h
rr l
```

これは 16 ビット値を 3 回右シフトしているため、

```text
速度 = 残り距離 ÷ 8
```

を計算しています。

例えば:

| 残り距離 | 移動量 |
|----------|--------|
| 80       | 10     |
| 40       | 5      |
| 16       | 2      |
| 8        | 1      |

となります。

目的地から遠いときは速く、近いときは遅くなります。

---

## 新しい位置を計算する

求めた移動量を現在位置へ加算します。

```asm
add hl, de
```

つまり毎フレーム

```text
現在位置 += (目標位置 - 現在位置) / 8
```

を実行しています。

この手法はゲームプログラムでよく使われる簡易イージングです。

---

## ハンチング防止

イージングでは目標値に近づくにつれて移動量が小さくなります。

そのままでは永遠に目標へ到達しない場合があります。

そこで残り距離が十分小さくなったら強制的に目標値へ固定しています。

```asm
cp 4
jr c, lock_position
```

```text
残り距離 < 4/256 ピクセル
```

になった時点で Y=88 に固定します。

---

## VRAM転送

VRAM に必要なのは整数座標だけです。

そのため小数部は転送せず、整数部以降の 4 バイトだけを送っています。

```asm
inc hl ; 小数部をスキップ
```

```asm
call LDIRVM
```

固定小数点で計算しながら、表示は通常のスプライトとして行っています。

---

## 実行結果

前回:

```text
T
 ↓
 ↓
 ↓
 ↓
```

一定速度で落下します。

今回:

```text
T
 ↓
  ↓
   ↓
    ↓
```

落下開始直後は速く、目的地に近づくほどゆっくりになります。

そのため機械的な動きではなく、タイトルロゴが吸い込まれるような自然な演出になります。

---

## このサンプルで学べること

- 固定小数点(Q8.8)による座標管理
- 残り距離を利用したイージング
- 距離に応じて速度を変化させる方法
- ハンチング防止処理
- ゲームやデモで利用できる自然なアニメーション手法

前回の `sc1_sp06` が「一定速度の落下アニメーション」だとすると、このサンプルは「減速付きの落下アニメーション」を実装したバージョンです。
