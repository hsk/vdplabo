
# SCREEN 1 でスプライトをキー操作で動かす

このサンプルは `sc1_sp02` の発展版です。

ソースコード: [sc1_sp03.asm](../sprite1/sc1_sp03.asm)

前回は複数のスプライトを表示するだけでしたが、このサンプルではカーソルキーを使ってスプライトを左右に移動できます。

---

## このサンプルでの変更点

初期化処理やスプライト登録処理は `sc1_sp02` とほぼ同じです。

追加された機能は次の 3 つです。

- カーソルキー入力の取得
- プレイヤー座標の管理
- 毎フレームのスプライト位置更新

---

## プレイヤー座標をRAMに保存する

プレイヤーのX座標をRAM上に保持します。

```asm
player_x equ 0C000h
```

初期値として X=100 を設定しています。

```asm
ld hl, player_x
ld (hl), 100
```

以降はこの値を増減させることでスプライトを移動します。

---

## カーソルキー入力を取得する

MSX BIOS の `GTSTCK` を使用すると方向キーの状態を取得できます。

```asm
xor a
call GTSTCK
```

返り値は A レジスタに格納されます。

| 値 | 方向     |
|----|----------|
| 1  | 上       |
| 3  | 右       |
| 7  | 左       |
| 5  | 下       |
| 0  | 入力なし |

このサンプルでは右方向と左方向だけを使用しています。

---

## 右移動処理

```asm
cp 2
jr c, end_right
cp 5
jr nc, end_right
inc (hl)
```

GTSTCK の返り値が 2～4 の場合に X座標を増加させています。

```text
↗  →  ↘
```

右上・右・右下を含む右方向入力で移動する実験用コードになっています。

---

## 左移動処理

```asm
cp 6
jr c, end_left
cp 9
jr nc, end_left
dec (hl)
```

GTSTCK の返り値が 6～8 の場合に X座標を減少させています。

```text
↖  ←  ↙
```

左上・左・左下を含む左方向入力で移動する実験用コードになっています。

---

## VSYNC待ち

毎フレーム一定速度で動作させるため、BIOS の JIFFY カウンタを利用して垂直同期を待っています。

```asm
ld hl, JIFFY
ld a, (hl)
vsync:
    cp (hl)
    jr z, vsync
```

JIFFY が更新されるまで待機することで、移動速度が安定します。
より高速にvsyncに入ったら処理をすぐ行いたい場合はH.TIMIの割り込みを使うのが良いのですが、お手軽にvsyncを取るならJIFFYを見るのが完結です。

---

## スプライト位置を更新する

更新された X 座標をスプライト属性テーブルへ転送します。

```asm
ld de, SPRATR + 1
ld hl, player_x
ld bc, 1
call LDIRVM
```

スプライト属性テーブルの 2 バイト目は X 座標なので、1 バイトだけ書き換えています。

---

## 実行結果

画面上のプレイヤースプライトが左右へ移動します。

```text
○      ○      ○
      ↑
   移動可能
```

両側のスプライトは固定され、中央のスプライトだけが移動します。

---

- RAM上での座標管理
- JIFFY を使った VSYNC待ち
- スプライト属性テーブルの一部分だけを更新する方法
