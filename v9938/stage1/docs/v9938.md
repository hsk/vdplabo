# [v9938.py](../v9938.py) について

[v9938.py](../v9938.py) は [v9938_graphics4.py](../v9938_graphics4.py)、[v9938_graphics5.py](../v9938_graphics5.py)、[v9938_graphics6.py](../v9938_graphics6.py)、[v9938_graphics7.py](../v9938_graphics7.py)、[v9938_sprite2.py](../v9938_sprite2.py)、[v9938_text2.py](../v9938_text2.py) を統合して１つにまとめたプログラムです。

[v9938.py](../v9938.py) は1ソースで動きます。

このステージでは１画面ごと一気に描画します。ですから、スプライトは全て描画されます。
スプライト表示機能は単体でのみ実行できますが、合成して表示することは今のところできません。

v9938.py は v9918.pyの機能は統合されていないことに気をつけてください。
