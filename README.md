# VDP の仕様を段階的に把握しよう

1. ステージ1 適当に機能ごとに作ってみる
    - 本質的に重要な機能を単純に作ってみる
        - レジスタは使わずに作る
        - VRAMの構成も考えない
        - ビットマップに描画するだけにする
        - 当たり判定などしない
        - 表示制限もしない

2. ステージ2 ラスタライズを意識する
    - ラインごとの描画をする
        - ラスタごとの表示制限をつけられる

3. VRAMのアドレスを確定させる
    - いい加減に作っていたVRAMの構造をしっかり確定させる

4. レジスタを確定させる
    - レジスタを使って扱うようにする

5. 機能を統合して１つにまとめる
    - v9918 として1つにまとめる
    - v9938 として1つにまとめる
    - v9958 として1つにまとめる
    - v9990 として1つにまとめる
6. v9918,v9938,v9958,v9990 を1つにまとめる
    - v9918 と v9938 を1つにまとめて v9938a とする
    - v9938a を v9958 をまとめて v9958a とする
    - v9958 と v9990 をまとめて v9978 とする
