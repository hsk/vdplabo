# VDP Labo

これは MSX の VDP を実装しながらゼロから理解するための研究です。
最初はVDPの本質的な要素のみを簡潔に実装して理解を深め、徐々に機能を厳密に作成していきます。

完成したMSXエミュレータを作ることよりも、VDPの各機能を段階的に実装し、その動作原理を理解することを優先します。

## ディレクトリ構成

### VDPチップ別の段階的研究 (メイン)

チップ(V9918/V9938/V9958/V9968/V9990)ごとに、下記の「進め方」のステージ1〜4を踏んで実装していく。各ステージの詳細は各ディレクトリのREADMEを参照。

| チップ | 概要 | 進捗 |
| --- | --- | --- |
| [v9918](v9918) | TMS9918A互換。stage1〜4まで実装あり | スプライト機能はstage4(レジスタ駆動)まで到達 |
| [v9938](v9938) | MSX2用。stage1にスプライト実装、他ステージはドキュメントのみ | 実装は一部、コマンド系はドキュメントのみ |
| [v9958](v9958) | MSX2+用。stage1のドキュメントのみ | 未実装 |
| [v9968](v9968) | 後継VDP(検討用)。ドキュメントのみ | 未実装 |
| [v9990](v9990) | MSXturboR用。stage1のドキュメントのみ | 未実装 |

### その他の研究ディレクトリ

- [sprite/](sprite) — スプライトモード1/2について、実機で動くZ80アセンブリのサンプルとBASICサンプルを集めた実地検証コード。VDPエミュレータ実装時の期待値の参考にする。
- [asm/](asm) — MSXの実ロム(アセンブリ)を使った実験群。ASCII16メガロムのデモ、R-Type風の敵/背景描画研究、キーフレームアニメーション実験など。
- [cpu/](cpu) — MSXに限らない、CPU+割り込み+VDPステータス的な概念を最小構成で学ぶための独立した教材。
- [timing/](timing) — エミュレーションにおける時間の進め方(フレーム単位〜クロック単位〜スケジューラ)についての解説。
- [vdp_command/](vdp_command) — V9938のVDPコマンド(HMMC/HMMMなど)を実機アセンブリで検証するテストROM集。
