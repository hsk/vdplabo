# sc2_field6 ネームテーブルだけで調整して空と地面を描画する

この実験の目的は、空の描画をカラーテーブルから分離し、ネームテーブルだけで地平線位置を制御できることを確認することです。

パターンテーブル書き換えは全て描画し、sc2_field4.asm をベースとしてネームテーブルだけで調整して空と地面を描画します。

## ネームテーブル側

表示構造は常に

```text
空
地面
```

という論理構造にします。

空に相当する領域には固定パターンを配置し、その下に地面パターンを配置します。

地平線位置はネームテーブルの配置によって決定します。

## カラーテーブル側

何も変えません。

カラーテーブルは従来通り全ての色を描画します。

## ネームテーブルをどう描くか

空に位置する箇所に空の固定パターンを描画し、その下に地面のパターンを描きます。

```text
+----------------+
| 空             |
| 空             |
| 空             |
+----------------+
| 地面           |
| 地面           |
| 地面           |
+----------------+
```

## 実装

bg_pattern_name_table_initは無くしてbg_pattern_name_table_drawを新設し毎回描画するようにしました。
bg_pattern_name_table_initはストライプのパターンで埋め尽くしていましたが、bg_pattern_name_table_drawでは空を描くよう修正しました。
WRTVRMを使った描画なのでだいぶ遅いですが高速化は次のsc2_field7で行います。

- 空の高さをネームテーブルだけで変更できる
