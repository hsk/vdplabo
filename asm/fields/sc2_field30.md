# sc2_field6 ドキュメント

天井は描画せず代わりに０番固定で描画する。
地面だけ描画する。

高速化したバージョンの描画方法もあるけど、高速化されたものは最適化されすぎていていじりづらいかもしれないから、field4のものをいじる感じでやってみる。

空を描く必要は本当はなくて、ネームテーブルを仮想描画するところの塗りで解決すればよくて、空の上の部分の描画を省略すればいい。
ってのが最終的なものになる。
ただここではアセンブラの練習も兼ねて、空のデータをPCG内部に書く仕組みで作ってみることにする。

## 空の描画

0からplayer_y+1の領域を0番の色で描画する。３つに領域が分かれているのでややこしいけどやればできる。

## 初期状態を作って飛び込む

高速に作ったものを変えずに最初だけ飛ばすには、途中の状態を作って処理の中に飛び込む。
今回のケースだとcolor_table_yに途中の状態を作って飛び込む。
player_y+1回進んだ状態を作って

B = 残り回数（ループカウンタ）
SP = ストライプデータ位置
HL = stripe_color_table2基準
VDPアドレス設定済み
C = 98h

などの状態を丁寧に作って地面だけ描画する。
