# field4 - SCREEN2用ストライプテーブル生成

このプログラムは、擬似3Dストライプの描画結果をリアルタイムに表示するのではなく、あらかじめテーブルとして生成し、MSXのSCREEN2で利用できるデータとして出力するツールです。

field2、field3ではPygame上でストライプを描画していましたが、field4では描画処理を行わず、各走査線の色番号だけを計算してZ80アセンブラ用のデータを生成します。

---

## 目的

MSXのSCREEN2ではラインごとの複雑な遠近計算を毎フレーム実行するのは負荷が高くなります。

そこでPC側であらかじめ計算した結果をテーブル化しておき、

```asm
ld hl,(現在の視点に対応するテーブル)
ld a,(hl)
```

のように参照するだけで遠近感のあるストライプパターンを利用できるようにします。

---

## 出力されるデータ

プログラムは地平線位置ごとに192ライン分の色番号を生成します。

色番号は

0
1
2
3

の4色を使用します。

地平線そのものは特殊値として

4

が出力されます。

これは

```python
if y == horizon_y:
    result.append(4)
```

によるものです。

---

## ストライプパターン

色番号は次の周期で変化します。

0 → 1 → 2 → 3 → 0 → ...

色番号の決定は

```python
color = int(ground_z + scroll_z) & 3
```

で行われています。

& 3 により結果は常に 0～3 の範囲になります。

---

## 地平線位置

テーブルは

```python
for horizon_y in range(8, 161, 8):
```

で生成されます。

つまり

8
16
24
...
160

の19種類の地平線位置に対応します。

---

## テーブル構造

出力は次のようになります。

```asm
stripe_table_1: ; y = 8
    db 0,0,1,1,2,...
    db ...
    ...
stripe_table_2: ; y = 16
    db ...
```

1テーブルは192ライン分です。

16ラインずつ区切って出力しているため、

db ...

が12行並びます。

---

## ポインタテーブル

最後に全テーブルへのポインタテーブルも生成します。

```asm
stripe_tables:
    dw stripe_table_1
    dw stripe_table_2
    dw stripe_table_3
    ...
```

MSX側では地平線位置に応じてこのテーブルを参照することで、目的のストライプテーブルを簡単に取得できます。

---

## 遠近計算

各ラインは field3 と同じ遠近計算を使用しています。

まず画面上のY座標から地平線までの距離を求めます。

その後、

```python
ground_z = 8 * horizon_distance / distance_from_horizon
```

によって地面上の奥行き座標を逆算します。

さらに field3 で導入した補正値 k を利用することで、

* 遠近感を自然に見せる
* 地平線付近をわずかに丸く感じさせる
* 平面よりも広い世界に見せる

という効果を得ています。

この補正は数学的な正確さよりも見た目を優先した「嘘の遠近法」です。

---

## SCREEN2での利用方法

このテーブルはSCREEN2の各ラインに対応する色やパターン番号を求めるために利用できます。

例えば、

```asm
ld hl,stripe_tables
; 視点番号を加算
; テーブル取得
ld a,(hl)
```

のように参照し、ラインごとの色やパターンを切り替えることで、スペースハリアーやレースゲームのような遠近感のあるフィールドを実現できます。

---

## まとめ

field4は、擬似3Dストライプをリアルタイム描画するのではなく、SCREEN2で利用するための事前計算テーブルを生成するツールです。

- 地平線位置ごとのテーブルを生成
- 各テーブルは192ライン分
- Z80アセンブラ形式で出力
- ポインタテーブルも同時生成
- field3の補正付き遠近法を継承

これにより、MSX実機では重い遠近計算を行わずに、事前生成したデータを参照するだけで擬似3Dフィールドを描画できます。
