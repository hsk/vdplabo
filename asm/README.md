# asm

MSXの実ロム(Z80アセンブリ、glass-0.6.jarでビルド)を使った実験群。性質の異なる4つのサブプロジェクトが入っている。

- [ascii16/](ascii16) — ASCII16メガロムのスロット切り替え(バンク切り替え)デモ。`RSLREG`/`ENASLT` を使って複数バンクを跨いだ実行を検証する。
- [enemies/](enemies) — R-Type風シューティングゲームの敵キャラクター描画研究。mz700版から抜き取った敵画像データの解析・変換スクリプトと、敵の出現/ズーム/描画ロジックのアセンブリ実装。
- [fields/](fields) — 同じくR-Type風の背景(地形)描画研究。カラーテーブル書き換えによる高速背景描画をPythonで試作してからアセンブリに移植している。
- [key/](key) — キーフレーム/モーショントゥイーン方式のアニメーション実験(`keyframe.cpp`, `r-type*.py`, `rtype_logo.py`)。現在は中断中。

`enemies/`, `fields/` は [sprite/](../sprite) でのVDPスプライト研究の実験場としても機能しており、実際にキャラクターを動かしながらVDPの挙動(スプライト制限・重ね合わせなど)を確認する場になっている。

その他: [int.asm](int.asm), [Makefile](Makefile), [todo.md](todo.md)(スプライト実験のBASIC/アセンブラサンプル集) はこのディレクトリ直下の補助ファイル。
