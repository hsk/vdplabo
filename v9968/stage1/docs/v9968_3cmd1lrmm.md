LRMM

　Logical Rotate vraM to vraM です。V9958 の他のコマンドの名前に習って命名しています。
　このコマンドは、回転拡大縮小を実現するコマンドです。少し癖のある設定値にはなりますが、その設定値さえ頑張って作れば、ハードウェアによる回転拡大縮小の描画処理が使える、というコマンドになります。
　こんな動きをします。この動画は、page1 (裏画面) の画像をちょっとずつ回転させて page0 (表示画面) へ描画しています。画面の外側にはみ出した部分は画像が無くなるので、動画では水色になっています。

LRMMの設定値

　(WSX, WSY), (WEX, WEY) は、転送元参照領域のウィンドウで、このウィンドウの外側を参照すると、転送元の画素の代わりに R#44 で指定した色が使われます。転送先とのロジカルオペレーションを実行後、転送先に描画されます。
　何かのキャラクターを回転させたい場合、その中心に回転中心を置きますが、(SX,SY) はあくまで参照の開始点なので、中心そのものを指定するわけではないのでご注意ください。この辺りの計算が必要になってきます。
　VX, VY は、小数部 8bit を持った固定小数点数です。なので回転させたい場合は、
　VX = INT( 256・COSθ )
　VY = INT( 256・SINθ )
を指定してください。256 が 1.0 相当で、数値を大きくすると縮小。小さくすると拡大になります。
