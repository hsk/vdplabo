LFMC

　Logical draw Font Cpu to vraM です。V9958 のVDPコマンドニーモニックは、転送先を先に書くルールで、名前の方は to を使って転送先を後に書くルールのようです。不思議なネーミングルールですが、今覆しても意味が無いので、そのルールを継承しています。
　このコマンドは、フォントデータを CPU から描画するコマンドです。LMMC はドット単位で書き込みますが、このコマンドは 8ドット単位で書き込むため、処理が軽くなっています。その代わり、２値画像しか描画できません。
画像
LFMCの設定値

　コマンド実行前に前景色は R#44 に、背景色は R#12 に指定します。コマンド実行後、水平 8ドット = 1byte で、順番に R#44 に書き込んで行きます。S#2 の TR bit が 1 になるのを待ってから書き込む手順です。
　NX が 8の倍数で無い場合は、その端数だけで 1byte を MSB側から消費していきます。残った bit は捨てられます。
　DIX, DIY がともに 0 であれば、下記のような走査順になります。
画像
LFMCの画素の走査順

　DIX が 1 なら左右反転。DIYが 1なら上下反転であることは、LMMC と同様です。
　動作してる様子。青背景に白文字が、LFMC による描画例です。
