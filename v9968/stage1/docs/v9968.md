# v9968

## v9968 拡張モード選択レジスタ

　v9968の機能を使うには、拡張モード選択レジスタ R#20 の対応するフラグを立てます。デフォルトは 00h でV9958互換の状態になります。

| REGNO | bit7 | bit6 | bit5 | bit4 | bit3 | bit2 | bit1 | bit0 |
| ----- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#20  | S16  | EVR  | ECOM | EPAL | SP3  | ILNS | SVNS | HS   |

- bit0 の HS は、VDP Command High Speed Mode フラグです。1でVDPコマンドが高速になります。0 では、V9958に近い速度になります。
- bit1 の SVNS は、Sprite Vertical position Non-following scroll フラグです。1で、スプライトが垂直スクロールの影響を受けなくなります。
- bit2 の ILNS は、Interrupt line position Non-following scroll フラグです。1で、走査線割り込みの走査線番号が垂直スクロールの影響を受けなくなります。
- bit3 の SP3 は、Sprite mode3 フラグです。1でSprite pattern generator table に、4bit/pixel のビットマップがある想定で、dot by dot で色づけされるスプライト表示になります。
- bit4 の EPAL は、Extended Palette フラグです。1で32768色からカラーパレットを選択するモードになります。Port#16 は256色に対応し Port#2 は1回目で赤2回目で緑、3回目で青を(0～31)の値で指定します。SCREEN8 の 256色も 32768色中256色のパレットに変わります。
- bit5 の ECOM は、Extended VDP command mode フラグで、0 でV9958互換モード、1 で拡張VDPコマンドモードになります。
    - ECOM=1でR#45のFG4=1にすると、どの画面モードでもGraphics4(SCREEN5) と同様のVDPコマンド処理が行われます。拡張スプライト操作に便利です。

        | REGNO | bit7 | bit6 | bit5 | bit4 | bit3 | bit2 | bit1 | bit0 |
        | ----- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
        | R#45  | `FG4` | XHR  | MXD  | MXS  | DIY  | DIX  | E0   | MAJ  |

- bit6 の EVR は、Extended VRAM フラグです。1で VRAM が 256KB に増えます。0 で 128KB 動作になります。
- bit7 の S16 は、1で全てのスプライトモード(Sprite mode1/Sprite mode2/Sprite mode3) でスプライトの水平最大表示数が16枚になります。
