# v9968

拡張モード選択レジスタ

　互換性を重視していますので、デフォルトでは V9958互換モードになっています。新機能を使うには、拡張モード選択レジスタに所定の値を書き込む必要があります。

　拡張モードレジスタは、R#20 になります。00h を書き込むとV9958互換です。

| REGNO | bit7 | bit6 | bit5 | bit4 | bit3 | bit2 | bit1 | bit0 |
| ----- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#20  | S16  | EVR  | ECOM | EPAL | SP3  | ILNS | SVNS | HS   |

- S16 は、1を書き込むと、Sprite mode1/Sprite mode2 でも、スプライトの水平最大表示数が 16枚まで拡張されます。Sprite mode3 を使うと従来の MSXturboR まででは動作しなくなってしまいますが、それらと互換性のあるソフトを作り、MSX2++ではスプライトの点滅を低減したい場合などに活用する機能です。（V9968が必須の環境では、Sprite mode3 を使うことをオススメします。）
