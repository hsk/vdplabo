# v9968 LFMM

　Logical draw Font vraM to vraM です。
　このコマンドは、VRAMに置かれているフォントデータを読み取って描画するコマンドです。8 x NY のフォントを 1文字とし、これを NX文字描画することになります。設定値は下記のようになります。
画像
LFMMの設定値

　SX, SY は、座標では無くアドレス指定として使います。R#32, #33 , #34 の 3byte に、256KB のどのアドレスにあるフォントデータを描画するかをリトルエンディアンで指定します。18bit のアドレスを A17…A0 とすると、A7～A0 を R#32、A15～A8 を R#33、A17～A16 を R#34 に指定します。R#35 は使いませんが 0 にしておきます。
　8 x NY の１文字単位で描画していきます。図では A,B,C,D,E と書かれている文字単位になります。そのため、下記のような変則的な走査順序になります。
　NX は、8 x NY を1文字とした、文字数を指定します。下図の例だと NX=5 ですね。
　漢字ROM の全角文字であれば、NY=16, NX=2 固定で、1文字単位で SX,SY にアドレスを指定して LFMM を実行するかたちになります。
