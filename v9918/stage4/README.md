# v9918/stage4

このステージでは、レジスタ(`reg[0..7]`)とステータスレジスタ(`stat[0]`)を導入し、実機のI/Oポート越しの制御に近い形でVDPを操作できるようにします。パターンテーブルやアトリビュートテーブルのアドレスもレジスタ経由で設定します。

- [x] [v9918_sprite1.py](v9918_sprite1.py) — レジスタ/VRAM/ステータスレジスタによるスプライト描画

ドキュメント

- [x] [docs/README.md](docs/README.md) — V9918のコントロールレジスタ(R#0〜R#7)・ステータスレジスタ(S#0)の仕様一覧
- [x] [docs/v9918_sprite1.md](docs/v9918_sprite1.md) — 実装フェーズの解説と機能チェックリスト

## このステージでできること

- `set_sprite_pattern_table`/`set_sprite_attribute_table` などレジスタ経由でのテーブルアドレス設定
- `get_5s()`/`get_5s_index()`/`get_collision()` によるステータスレジスタ経由の状態読み出し
- stage3までの描画機能(8x8/16x16、拡大、Y=208終端、EC、color0透過、1ライン4枚制限、5S、collision)をレジスタ駆動で再現
