# [v9958.py](../v9958.py) について

https://ngs.no.coocan.jp/doc/wiki.cgi/datapack?page=10%BE%CF+V9958%A4%CE%B2%E8%CC%CC%A5%E2%A1%BC%A5%C9

[v9958.py](../v9958.py) は [v9958_screen10.py](../v9958_screen10.py)、[v9958_screen12.py](../v9958_screen12.py) を統合して１つにまとめたプログラムです。

[v9958.py](../v9958.py) は1ソースで動きます。

このステージでは１画面ごと一気に描画します。ですから、スプライトは全て描画されます。
スプライト表示機能は単体でのみ実行できますが、合成して表示することは今のところできません。

v9958.py は v9918.py, v9938.py の機能は統合されていないことに気をつけてください。

MSX2+で追加された画面モードは10～12です。
SCREEN 10はSCREEN 5の拡張版、SCREEN 11,12はSCREEN 8の拡張版です。解像度に関しては変わらないですが、10および11に関しては12,499色、12では19,268色もの色から選べるようになっています。また色の指定方法もRGBではなくYJKという数値で指定します。なおMSX2の画面モードについては以下のページに書いています。
