# cpu

MSX(Z80)固有の実装ではなく、「CPU + 割り込み + VDPステータス的な概念」を最小構成で学ぶための独立した教材です。ACC/PC/zero_flag/stackを持つ簡易CPUと、VBlank・キーボード入力をIRQとして扱う仕組みをpygameで動かせます。

- [cpu.py](cpu.py) — 簡易CPU+割り込みエミュレータの実装
- [cpu.md](cpu.md) — レジスタ・命令セット・割り込み・キーボード・描画・実機(Z80/MSX)との対応表の解説

## 位置づけ

`v9918`〜`v9990` の研究がVDP(表示側)に特化しているのに対し、こちらはCPU側から見た「IN/OUT」「IRQ」「ステータスレジスタを読むとクリアされる」といった、VDPの `S#0` などにも共通する設計パターンを、より単純なオモチャCPUで体感するためのものです。
