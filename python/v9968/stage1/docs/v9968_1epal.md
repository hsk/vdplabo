# v9968 epal

## パレットの指定方法

| REGNO | bit7 | bit6 | bit5 | bit4 | bit3 | bit2 | bit1 | bit0 |
| ----- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#20  | S16  | EVR  | ECOM | `EPAL` | SP3  | ILNS | SVNS | HS   |

- V9958互換パレットモード
    - R#20 の EPAL を 0 でV9958 互換パレットモードになります。
    - パレットインデックスレジスタ R#16 に、色を設定したいパレット番号を書き込みます。パレットは Palette#0～#15 で下位 4bit のみ有効です。
    - 次にPort#2 に２回に分けて書き込み、１回目の bit0～bit2 は青を 0～7 で、bit4～bit6 は赤を 0～7 で、２回目の bit0～bit2 は緑を 0～7 で指定します。

- V9968拡張パレットモード
    - R#20 の EPAL を 1 でV9968 パレットモードになります。
    - パレットインデックスレジスタ R#16 に、色を設定したいパレット番号を書き込むところは互換モードと同じです。ただしパレットは Palette#0～#255 の 256種類ありますから、全ビット有効です。
    - 次にPort#2 に３回に分けて書き込み、１回目の bit0～bit4 は赤を 0～31 で。２回目の bit0～bit4 は緑を 0～31 で。３回目の bit0～bit4 は青を 0～31 で指定します。

- SCREEN0～7, 10, 11 のパレットも 32768色中16色になります。Palette#0～#15 が割り当てられます。Palette#16～Palette#255 はスプライトで利用します。

## Port#2 の扱い

　内部に 2bit のレジスタがあり、初期値は 0 で、R#16 に書き込んだタイミングでも 0 に戻ります。互換モードで Port#2 に書き込むと、その内部レジスタは、書く度に 0, 1, 0, 1 と切り替わります。これによって、赤青の設定なのか、緑の設定なのかを区別します。赤青だけ設定して、R#16 に何かを書き込むと、また赤青の設定に戻りますのでご注意ください。
　拡張モードでは、Port#2 に書く度に 0, 1, 2, 0, 1, 2 と切り替わっていきます。これによって、赤・青・緑のどの設定なのかを区別しています。2 になっている状態（つまり青を書き込んだ後の状態）で、R#20 の EPAL を 0 に戻しても、2 のままですが、互換モードで 2 は緑の設定タイミングとして扱われますので、不整合は生じません。
　3 になることは有りません。
