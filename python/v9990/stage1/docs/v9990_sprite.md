# スプライト (P1-P2)

スプライトのサイズは16x16で、スプライト属性テーブルには最大125個のスプライトを指定できます。
1つの水平ライン上に最大16個のスプライトを表示できます。

- スプライトの優先順位

各スプライトは、最前面レイヤーの前または後ろに表示できます。

スプライト属性テーブルで最初にリストされているスプライトは、最後にリストされているスプライトよりも優先度が高くなります。

- スプライト座標空間

スプライトは、通常の画像空間とは別の座標空間に存在します。スプライト座標 (0,0) は常に表示領域の左上になります。スプライト座標空間は 1024x256 で、表示の折り返しは端に沿って行われます。

- スプライト属性テーブル

|               | b7  | b6  | b5  | b4  | b3  | b2  | b1  | b0  |
| ------------- | --- | --- | --- | --- | --- | --- | --- | --- |
| オフセット +0 | Y7  | Y6  | Y5  | Y4  | Y3  | Y2  | Y1  | Y0  |
| オフセット +1 | PAT7| PAT6| PAT5| PAT4| PAT3| PAT2| PAT1| PAT0|
| オフセット +2 | X7  | X6  | X5  | X4  | X3  | X2  | X1  | X0  |
| オフセット +3 | SC5 | SC4 | P   | D   | -   | -   | X9  | X8  |

- Y7-Y0 : スプライトのY座標（実際の表示位置は指定位置より1行下になります）
- X9-X0 : スプライトのX座標
- PAT7-PAT0 : スプライトのパターン番号（パターンオフセットはR#25 SGBAで指定されます）
- P : P=0のときはスプライトが最前面レイヤーの前に、P=1のときは最前面レイヤーの後ろに配置されます。
- D : D=1の場合、スプライトは無効になります
- SC5-4 : スプライト色のパレットオフセット。

128個のスプライトエントリを格納できるスペースがありますが、実際に機能するのは最初の125個のみです。余分な12バイトはVDPによって使用されず、プログラマーの判断で自由に使用できます。

## スプライト表示機能

- サイズ
  - 16×16ピクセル
- 表示可能数
  - 1画面あたり125個
  - 1行あたり16個
- 表示色
  - 15色＋クリア色（各ピクセルごと）
  - スプライトごとにパレットを選択可能（4種類の中から1つを選択）
- 表示優先順位の指定
  - 各スプライトごとに、スプライトとパターンレイヤー間の優先順位を設定可能。スプライト間の優先順位はスプライト番号順となる。
- パターン
  - 256種類のパターンから選択
  - パターンデータはパターンレイヤーと共有される（ベースアドレスはレジスタR#25に設定する必要がある。）

### VRAM書き込みアドレス（書き込み専用） R#0-2

|               | b7  | b6  | b5  | b4  | b3  | b2  | b1  | b0  |
| ------------- | --- | --- | --- | --- | --- | --- | --- | --- |
| R#0           | A7  | A6  | A5  | A4  | A3  | A2  | A1  | A0  |
| R#1           | A15 | A14 | A13 | A12 | A11 | A10 | A9  | A8  |
| R#2           | AII | 0   | 0   | 0   | 0   | A18 | A17 | A16 |

- A18-A0 VRAM書き込みアドレス（ビット18～0）
- AII
  - 0 = VRAM書き込みアドレスは、P#0への書き込み終了時にのみ「1」分インクリメントされる。
  - 1 = インクリメントなし。

- A18-A0 VRAM 読み出しアドレス（ビット 7-0）

  - 1 = インクリメントなし。

### 画面モード（読み取り/書き込み） R#6,7

|      | b7   | b6   | b5   | b4   | b3   | b2   | b1   | b0   |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#6  |DSPM1 |DSPM0 |DCKM1 |DCKM0 |XIMM1 |XIMM0 |CLRM1 |CLRM0 |
| R#7  |    0 | C25M | SMI  | SM   | PAL  | EO   | IL   | HSCN |

- DSPM 表示モードの選択
  - 3 : スタンバイモード（非表示、VRAMリフレッシュなし、漢字ROM読み取り可能）
  - 2 : ビットマップモード（Bl-6）
  - 1 : P2モード
  - 0 : P1モード

- DCKM ピクセルクロックの選択（P#7のMCSと組み合わせて使用）

|   | MCS=0   | MCS=1    |                              |
| - | ------- | -------- | ---------------------------- |
| 2 | XTAL1   | MCKIN    |                              |
| 1 | XTAL1/2 | MCKIN/2  |                              |
| 0 | XTAL1/4 | *MCKIN/4 | （マスタークロックの分周数） |

\* 非公式設定

- XIMM：画像空間のX方向のピクセル数の指定（Y方向のピクセル数はXIMMとCLRMから自動的に算出されます）
  - 3：2048ピクセル
  - 2：1024ピクセル
  - 1：512ピクセル
  - 0：256ピクセル
- CLRM：ピクセルあたりのビット数の選択
  - 3：16ビット/ピクセル
  - 2：8ビット/ピクセル
  - 1：4ビット/ピクセル
  - 0：2ビット/ピクセル
- C25M 640×480モードの選択。HSCNが「1」の場合に有効。
  - 1 : B6モード
  - 0 : その他のモード
- SM1 NTSCのノンインターレース時の総垂直ライン数の選択
  - 1 : 263ライン（SMと組み合わせた場合、各フレームごとにサブキャリア位相が反転される。）
  - 0 : 262ライン
- SM 水平周波数の選択（B5およびB6モード時は無効）
  - 1 : 1H=fsc/227.5（各ラインごとに副搬送波の位相が反転する。）
  - 0 : 1H=fsc/228
- PAL：PALモードの選択（B5およびB6モード時は無効）
  - 1：垂直周波数がPAL仕様に変更される。
  - 0：垂直周波数がNTSC仕様に変更される。
- EO：インターレース時の垂直解像度の選択（B5およびB6モード時は無効）
  - 1：ノンインターレース時の2倍の垂直解像度
  - 0 : ノンインターレース時と同じ
- IL インターレースモードの選択（B5およびB6モード時は無効）
  - 1 : インターレース
  - 0 : ノンインターレース
- HSCN 水平ハイスキャンモードの選択
  - 1 : B5、B6モード
  - 0 : その他のモード

### 制御 (読み取り/書き込み) R#8

|      | b7   | b6   | b5   | b4   | b3   | b2   | b1   | b0   |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#8  | DISP | SPD  | YSE  | VWTE | VWM  |    0 |    0 |    0 |

- DISP 画面表示有効
  - 1 : VRAMの内容に従って画面に表示される。
  - 0 : 画面全体に背景色が表示される。
- SPD スプライト（カーソル）無効
  - 1 : スプライト（カーソル）は表示されない。
  - 0 : スプライト（カーソル）が表示される。
- YSE YS信号出力有効
  - 1 : YS信号が出力される。
  - 0 : YS信号が出力されない。（YS端子は常にローレベルのままとなる。）
- VWTE デジタル化中のVRAMシリアルデータバス入出力制御
  - 1 : 水平リトレースラインの間隔中にダミー書き込み転送が実行される。（VRAMのシリアルデータバスが入力端子となる。）
  - 0 : 水平リトレース期間中に読み出し転送が実行される。（VRAMのシリアルデータバスは出力端子となる。）
- VWM デジタル化中のVRAM書き込み制御
  - 1 : 水平リトレース期間中に書き込み転送が実行される。（表示期間中にVRAMのシリアルデータバスに入力されたデータは書き込み転送される。）
  - 0 : 書き込み転送は実行されない。

### 割り込み (読み取り/書き込み) R#9-12

|      | b7   | b6   | b5   | b4   | b3   | b2   | b1   | b0   |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#9  |    0 |    0 |    0 |    0 |    0 | IECE | IEH  | IEV  |
| R#10 | IL7  | IL6  | IL5  | IL4  | IL3  | IL2  | IL1  | IL0  |
| R#11 | IEHM |    0 |    0 |    0 |    0 |    0 | IL9  | IL8  |
| R#12 |    0 |    0 |    0 |    0 | IX3  | IX2  | IX1  | IX0  |

- IECE コマンド終了割り込み有効制御
  - 1 : P#6のCEフラグが「1」のとき、INT0端子がローレベルになる。
  - 0 : INT0端子はCEフラグに応じて変化しない。
- IEV 垂直リトレース期間中の割り込み有効
  - 1 : P#6のVIフラグが「1」のとき、INT0端子がローレベルになる。
  - 0 : INT0端子はVIフラグに応じて変化しない。
- IEH 表示位置割り込み有効（割り込み位置は、割り込みライン、割り込みX、およびIEHMで指定される。）
  - 1 : P#6のHIフラグが「1」のとき、INT1端子がローレベルになる。
  - 0 : INT1端子はHIフラグに応じて変化しない。
- IL 割り込みライン：表示位置割り込みが発生する垂直位置の指定（表示開始行を「0」として、行番号で指定します。）
- IX 表示位置割り込み X：表示位置割り込みが発生する水平位置の指定（表示開始位置を「0」として、64マスタークロック単位で指定します。）
- IEHM 表示位置割り込みの垂直位置の選択
  - 1：全ライン（Interrupt Lineの値は無視されます）
  - 0：指定したライン

### パレット制御 (書き込み) R#13

|      | b7   | b6   | b5   | b4   | b3   | b2   | b1   | b0   |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#13 |PLTM1 |PLTM0 | YAE  |PLTAIH|PLTO5 |PLTO4 |PLTO3 |PLTO2 |

- PLTM カラーパレットモードの選択
  - 3 : YUVモード
  - 2 : YJKモード
  - 1 : 256色モード
  - 0 : パレットモード
- YAE YJK（YUV）およびRGBの混合モードの選択（YUVおよびYJKモード時に有効）
  - 1 : YJK（YUV）画像とRGB画像を同時に表示します。
  - 0 : YJK（YUV）画像のみが表示される。
- PLTAIH カラーパレット読み出し時のパレット番号インクリメント制御
  - 1 : P#1の読み出しによってR#14のパレットポインタは変更されない。
  - 0 : P#1の読み出し後、R#14のパレットポインタがインクリメントされる。
- PLTO5-2 : 静止画パレット番号のオフセット

### パレットポインタ (書き込み) R#14

|      | b7   | b6   | b5   | b4   | b3   | b2   | b1   | b0   |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#14 |PLTA5 |PLTA4 |PLTA3 |PLTA2 |PLTA1 |PLTA0 |PLTP1 |PLTP0 |

- PLTA：パレット番号（カラーコード）
- PLTP：RGBの指定
  - 2：青
  - 1：緑
  - 0：赤

P#1へのアクセスが完了すると、1だけインクリメントされます。
PLTPは0～2の3進カウンタとして使用されます。

### 優先度制御 (読み取り/書き込み) R#27

|      | b7   | b6   | b5   | b4   | b3   | b2   | b1   | b0   |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| R#27 |    0 |    0 |    0 |    0 | PRY1 | PRY0 | PRX1 | PRX0 |

- PRY : P1モード時、レイヤー「A」と「B」の表示優先順位を入れ替える表示Y座標を指定します。単位は64行で、指定した行より下（その行を含む）の範囲ではレイヤー「B」が優先されます。「0」に設定すると、その範囲全体でレイヤー「A」が優先されます。
- PRX : P1モード時、レイヤー「A」と「B」の表示優先順位を入れ替える表示X座標を指定します。64ピクセル単位で指定され、指定したピクセルの右側（そのピクセルを含む）の範囲では、レイヤー「B」が優先されます。「0」の場合、その範囲全体でレイヤー「A」が優先されます。

\<Example\> When PRX=2 and PRY=2

|     |       | 1   | 2   | 3   | 0   | (PRX)   |
| -   | ---   | --- | --- | --- | --- | ------- |
|     | 0     | 64  | 128 | 192 | 256 | (pixel) |
| 1   | 64    | A   | A   | B   | B   |         |
| 2   | 128   | A   | A   | B   | B   |         |
| 3   | 192   | B   | B   | B   | B   |         |
| 0   | 256   | B   | B   | B   | B   | (211)   |
|(PRY)|(pixel)|     |     |     |     |         |

| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
