# v9938

MSX2用VDP。V9918(TMS9918A互換)を土台に、GRAPHIC3〜7モード・スプライトモード2・VDPコマンド(HMMC/HMMM等)・カラーパレットなどが追加されている。[ルートREADME](../README.md)の「研究の進め方」のうち、実装が進んでいるのはstage1のみで、他は着手前かドキュメント段階。

| ステージ | 概要 | 状態 |
| --- | --- | --- |
| [stage1](stage1) | 適当に機能ごとに作ってみる | スプライトモード2のみ実装、他はドキュメントのみ |
| [stage2](stage2) | ラスタライズを意識する | 未着手(TODOリストのみ) |
| stage3 | VRAMのアドレスを確定させる | ディレクトリ未作成 |
| [stage4](stage4) | レジスタを確定させる | コントロール/ステータスレジスタの仕様書のみ(実装なし) |

## stage1 — 適当に機能ごとに作ってみる

- `v9938_sprite2.py` — スプライトモード2(パレット+スプライト単位カラーテーブル)の実装
- `docs/v9938_graphics4.py` — GRAPHIC4(SCREEN5)の実装サンプル

ドキュメントは充実しており、GRAPHIC3〜7の各モード解説、VDPコマンド(HMMC/YMMM/HMMM/HMMV/LMMC/LMCM/LMMM/LMMV/LINE/SRCH/PSET/POINT)の解説、GRAPHIC4向けコマンド解説(`docs/g4/`)が揃っている。一方、実装(.py)があるのはスプライトモード2とGRAPHIC4のみで、GRAPHIC3/5/6/7・TEXT2・VDPコマンド類の実装はこれから。実機でのVDPコマンド検証は [asm/vdp_command/](../../asm/vdp_command) を参照。

## stage2 — ラスタライズを意識する

v9918/stage2と同じ方針(ラインごとの描画、ラスタごとの表示制限)を目指すが、ファイルはREADMEのTODOリストのみでまだ何も実装されていない。

## stage3 — VRAMのアドレスを確定させる

ディレクトリ自体がまだ作られていない。stage1のスプライトモード2実装をVRAM経由に書き換えるところから着手する必要がある(v9918/stage3が先行例)。

## stage4 — レジスタを確定させる

`stage4/README.md` にV9938のコントロールレジスタ(R#0〜R#23、R#32〜R#46)とステータスレジスタ(S#0〜S#9)の仕様が一覧化されている(モードレジスタ・テーブルベースアドレスレジスタ・カラーレジスタ・ディスプレイレジスタ・アクセスレジスタ・コマンドレジスタ)。`v9938_sprite3.md`はこのレジスタ仕様を踏まえたスプライト実装の構想メモ。ただし、いずれもドキュメントのみでレジスタ駆動の実装(.py)はまだない。v9918/stage4が先行実装例。
