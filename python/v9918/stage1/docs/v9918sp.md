# [v9918sp.py](../v9918sp.py) について

[v9918sp.py](../v9918sp.py) は [v9918_graphics1.py](../v9918_graphics1.py)、[v9918_graphics2.py](../v9918_graphics2.py)、[v9918_graphicsmc.py](../v9918_graphicsmc.py)、[v9918_sprite1.py](../v9918_sprite1.py)、[v9918_text1.py](../v9918_text1.py) を統合して１つにまとめたプログラムです。

[v9918sp.py](../v9918sp.py) は1ソースで動きます。

このステージでは１画面ごと一気に描画します。ですから、スプライトは全て描画されます。
スプライト表示機能のROMは並列的に呼ばれて動きます。
