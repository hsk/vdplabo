# v9918/stage3

このステージでは VRAM を用いて実装します。ステージ1/2ではオブジェクトの属性を直接Pythonの変数として保持していましたが、ここからはスプライトアトリビュートテーブル(SAT)・スプライトジェネレータテーブル(SGT)を VRAM 上のバイト列として扱い、そのアドレスも可変にします。

- [x] [v9918_sprite1.py](v9918_sprite1.py) — VRAM経由でのスプライト描画(SAT/SGTアドレス可変)
- [x] [sanko.cpp](sanko.cpp) — 他実装のスプライト描画ロジック(比較参考用)

ドキュメント

- [x] [docs/v9918_sprite1.md](docs/v9918_sprite1.md) — 実装フェーズの解説と機能チェックリスト

## このステージでできること

- SAT/SGTをVRAM上のデータとして参照(アドレス可変)
- 8x8/16x16スプライト、2倍拡大、1ライン4枚制限
- Y=208終端、Early Clock(EC/X-32)、color 0 transparent
- 5th Sprite(5S)フラグ、衝突(collision)判定
- 実ROM/BIOS互換のVRAMレイアウトに近づける

`docs/v9918_sprite1.md` 内のフェーズ3チェックリストは一部未チェックのまま残っているが、実装(`v9918_sprite1.py`)には上記の機能が既に含まれている。ドキュメントの更新が追いついていない箇所なので、今後整備が必要。
